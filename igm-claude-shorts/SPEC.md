# SPEC — C-Level을 위한 Claude 에이전트 경영 (IGM) 쇼츠

GOAL:    대표이사가 "AI에게 질문하던 리더 → 에이전트에게 일을 맡기는 리더"로 바뀌는 2일을 보고, 신청 페이지(igm.or.kr)로 간다.
OUTPUT:  HyperFrames, 1080 x 1920 (9:16), 30 fps
TIME:    60 s x 30 = 1800 frames. 음악 없음(음원 소스 미연결) — 무음 피드 재생을 전제로 타이포가 모든 것을 전달.
SOURCE:  https://igm.or.kr/class/view/606337 (커리큘럼·일정·강사 정보만 사용, 수치 창작 금지)

LOOK:    포스터 평면(poster planes). 단색 지면 3개를 컬러 플러드로 교대:
         ivory #F0EEE6 / ink #141413 / clay #D97757. 그라데이션·글로우·글래스 없음.
         clay 위 글자는 ink, ink 위 강조는 clay, ivory 위 강조는 clay 형광펜 띠 + ink 글자.
         보조 회색 #8A8780 (지나간 말, 부정되는 말).
         Display: Pretendard Black 900, 히어로 130–300 px, tracking -0.03em, line-height 1.0.
         Body: Pretendard Bold 700 / Medium 500, 44–110 px. 28 px 미만 텍스트 없음.
         좌측 정렬, 좌 여백 96 px, 텍스트 우측 끝 ≤ 940 px(우측 액션 레일 회피).
         모든 글자는 y 168–1330 px 밴드 안.
OBJECTS: 질문에 그어지는 취소선(clay 바), 슬롯머신 단어창(연결 대상이 굴러감),
         컴퍼니 브레인 = 3장의 ink 판(스킬 라이브러리 / MCP 허브 / LLM Wiki)이 쌓임,
         신청 버튼 = ink 사각 판 + ivory 글자.
MOTION:  도착 expo.out / power4.out(0.3–0.5 s), 플러드 power2.inOut 0.35–0.45 s,
         퇴장 power3.in 0.2–0.3 s(도착보다 40–50% 짧게). 판 쌓기만 back.out(1.4).
         단어 stagger 0.07–0.1 s, 글자 0.06–0.08 s. 착지한 제목은 정지.
         등장 방식 순환: 단어별 blur-in / 회색→잉크 / 글자별 / 슬램(scale 1.25→1) / 슬롯 롤 / 카운트업 / 형광펜.
SHOTS:   s01 0.0–4.0   훅. 0프레임에 "대표님, 아직도 AI에게 질문만" — 1.0s "하십니까?", 2.0s 취소선. 위로 휩.
