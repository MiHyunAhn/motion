# 에이전트 경영 쇼츠 시리즈 (3부작)

대상: 대표이사·C-Level. 한 가지 메시지: **대표님은 일을 하는 사람이 아니라, 에이전트에게 일을 맡기고 결정하는 사람이어야 한다 — 그것이 에이전트 경영.**

공통: 1080×1920, 30 fps, 키네틱 타이포, 음성 없음, 효과음만(번들 Pixabay SFX).
룩: ivory #F0EEE6 / ink #141413 / clay #D97757, Pretendard 900/700/500, 좌측 정렬 96 px, 텍스트는 y 168–1330 밴드 안.
연결: 각 편 엔드카드에 "에이전트 경영 시리즈 EP.n" + 다음 편 예고, 마지막 편에만 IGM 과정 신청 CTA.
사실 관계: 시간·횟수 같은 숫자는 이해를 돕기 위한 연출이며 화면에 "※ 이해를 돕기 위한 예시"로 표시. 과정 정보는 https://igm.or.kr/class/view/606337 에서만 가져옴.

## EP.1 대표님의 월요일 (~36 s) — 하루의 한 순간 × 한 프레임이 다시 짜임
- 0프레임: 검은 화면에 "월요일 09:00 / 보고서, 아직입니까?"
- 비트: 09:00 보고서 대기 → 11:30 회의 자료 또 수정 → 15:00 경쟁사 분석 다음 주에 → 19:00 오늘 내린 결정 0 → 같은 월요일, 시계가 09:00으로 되감김 → 에이전트가 처리한 일이 시계 아래 쌓임 → 대표님은 결정만 → 오늘 내린 결정 3 → "일하는 리더에서 맡기는 리더로" → EP.1 엔드카드(다음 편: 묻는 AI, 맡기는 AI)
- 소리: 시간이 바뀔 때 키 소리, 0에 저음 임팩트, 되감기에 휙 소리.

## EP.2 묻는 AI, 맡기는 AI (~35 s) — 비포/애프터 × 분할 화면이 하나로
- 0프레임: "같은 지시, “경쟁사 분석해줘”"
- 비트: 화면이 위(묻는 AI, ink)·아래(맡기는 AI, clay)로 나뉨 → 위: 대표님이 복사하고·붙여넣고·표로 정리하고·메일 쓰고·다시 묻는다(카운터 1→5) / 아래: 데이터 수집·분석·보고서·대시보드·공유가 차분히 완료 → 위 화면이 접히고 아래가 전체가 됨 → "대표님이 한 일은 검토하고 결정했다" → "답을 받는 AI ✕ / 결과를 받는 AI" → EP.2 엔드카드(다음 편: 김 부장이 떠나던 날)
- 소리: 위쪽 동사에 클릭, 아래쪽 완료에 팝, 접힐 때 휙 소리.

## EP.3 김 부장이 떠나던 날 (~45 s) — 이야기 × 오브젝트가 다음 장면이 되는 체인
- 0프레임: "김 부장이 퇴사했다"
- 비트: 노하우도 함께 → 몇 달 뒤, 그 일을 아는 사람이 없다 → 김 부장의 업무 노트가 "영업보고.skill"로 변신 → 스킬 판이 하나씩 쌓여 컴퍼니 브레인 → 신입도 첫날부터 김 부장처럼 → "에이전트 경영은 기술이 아니라 경영입니다" → 시리즈 엔드카드 + IGM 과정 CTA
- 소리: 퇴사에 저음 임팩트, 변신에 휙 소리, 판이 쌓일 때 팝, 결론에 임팩트.
